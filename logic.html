列组内部结构 — 分区目录 → part 文件 → Row Group → Vector
每个列组内部按 month=YYYY-MM 分区，分区内是 part 文件（Parquet），part 内是 Row Group（默认 16384 行）

🔍 Part 解剖
0000-0000005998.parquet
├ 文件名 = {idx:04d}-{rows:010d}
├ idx = 分区内序号（0000 起）
├ rows = 文件总行数（10 位定宽）
├ 行区间 = 文件名累加推导
│  start_row = 分区起点 + Σ(更小 idx part 行数)
├ 格式 = Parquet（ZSTD 压缩）
├ 列 = 组 schema 的子集（evolution）
└ RG = Row Group（默认 16384 行）
读 part 时 零 footer IO：行区间从文件名已知
{ "name": "cnstk_ixday", "version": 1, "rg_rows": 16384, // Writer flush 的 RG 大小（可选，默认 16384） "part_rows": 4194304, // 目标 part 大小提示（读端不用） "last_txid": 42, // 最近成功提交的事务号 "groups": ["index", "factor/alpha101", "factor/alpha191", "fieldset/ma", …], "partitioning": { "index": [{"template":"month=%Y-%m","source":"date"}], "factor/alpha101": [{"template":"month=%Y-%m","source":"date"}] } } // groups 字段读端永不解析（Group 发现唯一路径 = glob）；唯一例外 = 空表起步给 Writer 提供骨架
分区对齐唯一契约：所有组用同一种一层分区段（year= / month= / date=）· 共享分区总行数必须一致
跨组行号对齐 — index[N] == alpha[N] == ma[N]，查询时直接组装进同一个 DataChunk
三个组在 month=2026-09 分区各有 5998 行 → 总行数一致 ✓ · 同色 RG 跨组等高 = 同一逻辑行区间
